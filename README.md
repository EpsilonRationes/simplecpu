# scpu — Простой процессор в консоли

Консольная утилита для учебного [Простого процессора](https://simplecpu.ru/):
8-разрядный процессор, 4 регистра общего назначения (R0–R3), регистр флагов RF,
указатель команд RC и 256 байт памяти.

- **Сборка** — на сервере simplecpu.ru (ассемблер закрытый), поэтому для первой
  сборки нужен интернет. Удачные сборки кэшируются в `~/.cache/scpu/`, и повторный
  запуск того же файла работает офлайн.
- **Выполнение** — локально, точный порт виртуальной машины сайта.

## Установка

```bash
cargo install --path .
# или просто собрать: cargo build --release  →  target/release/scpu
```

## Использование

```bash
scpu build prog.sasm                    # проверить сборку
scpu run prog.sasm                      # выполнить, ввод/вывод по шаблону
scpu run prog.sasm --tui                # интерфейс как на сайте
scpu run prog.sasm --in 0xF0=5 --in 0xF1=-2   # ввод без вопросов (для скриптов)
scpu run prog.sasm --dump               # после остановки показать регистры и память
```

`scpu build` выводит «Сборка успешна» или ошибки сервера с номерами строк:

```
$ scpu build bad.sasm
Строка   1: Неизвестная инструкция.
```

## Шаблон ввода/вывода

Описывается спец-комментариями прямо в программе. Сервер их игнорирует, так что
файл без изменений собирается и на сайте.

```asm
; Сумма двух чисел
; scpu-in:  @0xF0 "A в ячейку 0xF0: "
; scpu-in:  @0xF1 "B: "
; scpu-out: "A+B = {@0xF2:s}  (без знака {@0xF2:u}, hex {@0xF2:x})"

        r0 <- @0xF0
        r1 <- @0xF1
        r0 <- r0 + r1
        @0xF2 <- r0
HLT:    rc <- @HLT
```

```
$ scpu run examples/sum.sasm
A в ячейку 0xF0: 5
B: -2
A+B = 3  (без знака 3, hex 03)
```

**`scpu-in: @АДРЕС "приглашение"`** — перед запуском спросить число и записать его
в ячейку. Принимаются `5`, `-2`, `0x1F`, `0b101`, диапазон от -128 до 255
(отрицательные хранятся в дополнительном коде). Приглашение можно не указывать.
Вместо одной ячейки можно указать диапазон, как в задании:
`; scpu-in: @0xD0...0xDF "числа для взятия модуля: "` — вводятся все значения
через пробел одной строкой (ровно столько, сколько ячеек). Вывод диапазона —
`{@0xF0...0xFF:s}`: значения через пробел.
Ключ `--in АДРЕС=ЗНАЧЕНИЕ` задаёт значение без вопроса.

**`scpu-out: "текст"`** — печатается после остановки программы. Каждая строка
`scpu-out` выводится отдельной строкой. Подстановки:

| Подстановка          | Что подставляется |
|----------------------|-------------------|
| `{@0xF2:ф}`          | ячейка памяти     |
| `{r0:ф}` … `{r3:ф}`  | регистр общего назначения |
| `{rc:ф}`, `{rf:ф}`   | указатель команд, флаги |

Формат `ф` обязателен:

| Формат | Пример для 0xFE |
|--------|-----------------|
| `s` — со знаком   | `-2` |
| `u` — без знака   | `254` |
| `x` — hex         | `FE` |
| `b` — двоичный    | `11111110` |

Внутри строки работают `\n`, `\t`, `\"`, `\\`, а фигурные скобки как символы
пишутся так: `{{` и `}}`.

Если в программе нет `scpu-out`, после остановки печатаются регистры.

## TUI (`--tui`)

```
┌ Память ───────────────────────────────────────────┐┌ Регистры ──────────────────────┐
│   00 01 02 03 04 05 06 07 08 09 0A 0B 0C 0D 0E 0F ││R0  00000011  03    3   3       │
│00 10 F0 14 F1 41 20 F2 C0 07 00 00 00 00 00 00 00 ││R1  11111110  FE   -2 254       │
│...                                                ││...                             │
│F0 05 FE 03 00 00 00 00 00 00 00 00 00 00 00 00 00 ││RF  00000100  04    4   4  C S Z│
└───────────────────────────────────────────────────┘└────────────────────────────────┘
                                                     ┌ Исходник ──────────────────────┐
                                                     │  5 HLT: rc <- @HLT             │
Шагов: 5   Остановка (HLT)                           └────────────────────────────────┘
```

- **Память:** текущая инструкция выделена, ячейка, изменённая последним шагом, — красная.
- **Регистры:** биты (изменившиеся — красные), hex, значения со знаком и без, флаги C S Z.
- **Исходник:** подсвечена строка текущей инструкции.

| Клавиша       | Действие |
|---------------|----------|
| `n`, пробел   | шаг |
| `p`           | старт/стоп автовыполнения |
| `r`           | сброс (регистры и память к состоянию после ввода) |
| `s`           | скорость автовыполнения (4 уровня) |
| `e`           | правка ячейки или регистра: `0xF0=5`, `r1=-3`, `rc=0` |
| `q`, `Esc`    | выход |

Ввод по `scpu-in` запрашивается до открытия интерфейса, вывод `scpu-out` печатается
после выхода, если программа дошла до HLT.

## Остановка и коды выхода

Программа считается остановившейся, когда команда не меняет RC — как на сайте.
Обычно для этого пишут `HLT: rc <- @HLT`.

| Код | Значение |
|-----|----------|
| 0   | успешно |
| 1   | ошибка сборки, шаблона или аргументов |
| 2   | ошибка выполнения (деление на ноль, недопустимый код операции) — с адресом и строкой |
| 3   | программа не остановилась за 1 000 000 шагов (нет HLT?) |

## Особенности процессора

Поведение перенесено из JS сайта один в один, включая особенности:

- вычитание и сравнение считаются как `d + (−s mod 256)`, поэтому `5 − 5` даёт Z=1 **и** C=1;
- C выставляется по 8-му биту результата (в том числе при умножении);
- деление беззнаковое;
- RC после 0xFF переходит на 0x00.

## Устройство

| Файл | Назначение |
|------|------------|
| `src/main.rs`      | команды `build`/`run`, ввод, дамп |
| `src/assembler.rs` | запрос к `https://simplecpu.ru/assemble`, кэш |
| `src/program.rs`   | разбор машинного кода от сервера (`HEX:СТРОКА;...`) |
| `src/vm.rs`        | процессор |
| `src/template.rs`  | шаблоны ввода/вывода |
| `src/tui.rs`       | интерфейс |
| `site/`            | сохранённые страницы и JS сайта (источник для порта VM) |

Тесты: `cargo test`.
